# Nitank Website Clone

A complete, responsive clone of the nitank.co.il website - a professional Israeli business website for industrial kitchen cleaning solutions.

## 📋 Project Overview

This project is a modern, responsive website clone that closely matches the original nitank.co.il website structure, design, and user experience. The website is built with pure HTML5, CSS3, and JavaScript, following best practices for web development and Israeli business website standards.

## ✨ Features

### 🎨 Design & Layout
- **Responsive Design**: Mobile-first approach that works seamlessly on all devices
- **Professional Israeli Business Aesthetic**: Blue color scheme reflecting trust and professionalism
- **Modern UI/UX**: Clean layout with smooth animations and transitions
- **Accessibility Compliant**: WCAG guidelines with proper ARIA labels

### 📱 Pages Included

1. **Homepage (index.html)** - Hero section, services overview, testimonials
2. **About Page (about.html)** - Company story, mission, vision, team
3. **Services Page (services.html)** - Detailed service descriptions
4. **Contact Page (contact.html)** - Contact form, information, FAQ

### 🚀 Interactive Features

- Mobile hamburger menu
- Form validation with Hebrew error messages
- Smooth scrolling
- Back to top button
- Success notifications
- Fade-in animations

## 🚀 Getting Started

Simply open `index.html` in your web browser. No installation required!

## 📁 Project Structure

```
├── index.html          # Homepage
├── about.html          # About page
├── services.html       # Services page
├── contact.html        # Contact page
├── style.css           # Main stylesheet
├── script.js           # JavaScript functionality
└── README.md           # Documentation
```

## 🎨 Customization

Edit CSS variables in `style.css` to change colors:

```css
:root {
    --primary-blue: #003d7a;
    --secondary-blue: #005eb8;
}
```
